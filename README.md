# Сервис управления фестивальными площадками

## Назначение

Приложение помогает организаторам фестивалей подбирать и бронировать площадки: проверять
вместимость, доступность на нужную дату и формировать расписание мероприятий на площадке.
Сервис решает задачу быстрого сопоставления параметров фестиваля (ожидаемое количество
посетителей, дата проведения) с характеристиками доступных площадок.

## Целевая аудитория

- организаторы фестивалей и культурных мероприятий;
- администраторы площадок (парков, концертных залов, открытых пространств);
- координаторы, составляющие расписание фестивальных программ.

## Предметная область

Организация фестивалей требует учёта множества площадок с разной вместимостью,
расписанием занятости и набором организаторов, ответственных за проведение мероприятий.
Предметная область охватывает подбор площадки под фестиваль, проверку её доступности
и ведение расписания использования.

## Основные сущности

- Фестиваль — мероприятие с названием, датой проведения и ожидаемым числом посетителей.
- Площадка — место проведения с названием, вместимостью и статусом доступности.
- Организатор — ответственное лицо или организация, проводящая фестиваль.
- Расписание — привязка фестиваля к площадке на определённую дату.

## Основные функции

- проверка соответствия вместимости площадки ожидаемому числу посетителей фестиваля;
- проверка доступности площадки на выбранную дату;
- регистрация организатора, ответственного за бронирование;
- формирование итогового статуса возможности проведения фестиваля на площадке.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
